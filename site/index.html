快速开始

三条命令跑起本地环境，或用一键按钮部署自己的云端。

本地运行

  1. git clone https://github.com/wjh941/ai-resume
  2. 后端：cd resume-backend → 配置 .env（AI_API_KEY 等）→ uvicorn main:app --reload
  3. Web：cd web-frontend → npm install && npm run dev
  4. 小程序：cd resume-miniprogram → npm run dev:h5
🔑 演示登录：手机号 13800138000，验证码 123456（无需真实短信）。

一键云端部署

  1. 后端：点击下方 Deploy to Render（蓝图已备好 render.yaml）
  2. 前端：Vercel 导入仓库，Root Directory 设为 web-frontend
  3. 回填环境变量：VITE_API_BASE_URL = Render 域名，CORS_ORIGINS = Vercel 域名

免费档说明：后端闲置约 15 分钟休眠，首访需 30-50 秒唤醒（已内置唤醒提示与自动保活）。
