# 职业测评与年度洞察操作说明

## 功能边界

职业测评用于帮助求职者整理兴趣偏好、工作方式、可举证的专长和现实约束。它不是心理或医疗诊断，也不预测录用概率、薪资或岗位结果。

测评结果包含：

- 兴趣偏好：只展示评分较高的方向，低分或未作答不会被当作优势。
- 专长证据：只记录用户表示能够举出真实例子的能力。
- 现实约束：用于安排学习和投递节奏，不作为岗位筛除条件。
- 7 / 30 / 90 天行动计划：包含简历证据整理、可交付练习、模拟面试和复盘检查点。

## 用户操作

1. 从首页点击“职业测评”，依次完成兴趣偏好、工作方式、专长证据和现实约束四组题目。
2. 每题按 1 到 5 分选择；可以跳过题目。跳过不会形成任何能力结论。
3. 点击“生成测评建议”后，结果按匿名 `client_id` 写入本地 SQLite。
4. 点击“结合专业生成职业规划”，在职业规划页面填写专业、技能与偏好，获得冲刺、稳妥、保底三档方向建议。

## 年度就业洞察资料规范

年度洞察只允许录入已经下载并归档的公开静态资料摘要，例如政府部门、教育部门或高校公开发布的就业报告、专业目录或职业分类资料。

每条资料必须完整记录：

- `year`：资料对应年份。
- `scope`：适用区域或范围。
- `audience`：适用人群，例如“高校毕业生”。
- `category`：洞察类别，例如“就业趋势”或“能力准备”。
- `title` 与 `content`：简洁、可核对的本地摘要。
- `source_label`：可识别来源名称。
- `publication_date`：原资料发布日期，使用 `YYYY-MM-DD`。
- `confidence_note`：说明资料覆盖范围、摘要限制或不确定性。

后端提供以下本地接口，便于在受控环境中录入和读取资料：

```text
POST /api/career/annual-insights
GET  /api/career/annual-insights?year=2025
```

录入接口仅保存请求中提供的本地摘要与来源字段，不会下载网页或抓取职位描述。年度洞察为空时，小程序不会显示洞察卡片，不影响测评、简历或职业规划功能。

## 禁止的数据获取方式

项目禁止新增或使用以下能力：

- 招聘网站爬虫、批量抓取职位描述或绕过登录。
- 浏览器自动化、Cookie 处理、验证码绕过或账号模拟。
- 将未经来源标识的网络片段当作市场事实写入数据库。

如需扩充岗位或专业知识库，应使用本地 Excel、公开的静态 CSV/JSON、官方分类文本或已经授权的数据接口，并保留来源、版本和更新时间。

## 数据与隐私

测评答案、结果、职业画像与简历草稿默认存储在本地 SQLite。部署到服务端前，应明确数据保留周期、备份策略和用户告知方式；不要把测评结果用于歧视性筛选或自动化淘汰。
