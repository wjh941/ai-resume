# 合规知识库与简历平台增强设计

## 目标

在不使用招聘网站爬虫、网页抓取、批量 JD 抓取或登录绕过的前提下，增强本地岗位知识库、简历管理、模型配置和部署能力。

## 合规边界

- 仅接受人工维护、Excel 文件、本地 TXT 静态文件和公开授权的官方分类文本。
- 不新增 HTTP 页面抓取、浏览器自动化、招聘网站 URL 解析、Cookie 使用或反爬绕过代码。
- 导入记录保存来源类型与来源文件名，默认标记为 `manual`、`excel` 或 `official_text`。

## 阶段一：知识库

- 使用 `openpyxl` 生成标准 Excel 模板、校验并导入岗位/专业。
- Excel 表包含岗位、专业两个工作表；必填字段缺失、重复岗位或非法难度在预览阶段返回错误，不写入数据库。
- 新增本地 TXT 解析 CLI，仅接受人社职业分类和高校专业目录等已下载文本。每行以 `岗位：`、`专业：` 或 TSV 格式解析；不读取网络地址。
- 岗位库提供后台 API：分页列表、创建、更新、删除、模板下载、预览导入、确认导入、导出。

## 阶段二：简历与模型

- 匹配算法扩展为：专业关联、课程/技能覆盖、身份可行性、偏好、岗位来源可信度；结果保留可解释评分。
- 新增确定性简历风险检测：联系方式、目标岗位、时间范围、过度空泛描述、未确认占位符和不可信量化数字提示。只提示，不自动篡改事实。
- 新增 `resume_version` 表，保存草稿快照；支持版本列表、恢复、比较。
- 新增 Markdown 导出，沿用临时下载与文件名规则。
- 模型配置保存非敏感 Provider Profile；API Key 仅通过环境变量名读取，响应中永不返回密钥。

## 阶段三：前端、部署与文档

- 新增小程序知识库管理页，可查看、手动新增/编辑/删除岗位和专业，导入/导出 Excel。
- 新增模型设置页，选择已启用服务商配置并显示密钥环境变量提示。
- 新增 `.env.*` 前端环境文件和统一 API 地址读取，H5/微信小程序不再在源代码里硬编码本地后端地址。
- 提供 SQLite、MySQL、PostgreSQL 的完整基线建表脚本及迁移说明。
- README 和独立合规数据管理文档包含导入模板、TXT 格式、数据库迁移和部署流程。

## 数据模型

- `knowledge_import_log`: 导入批次、来源类型、文件名、成功/失败条数、创建时间。
- `resume_version`: 版本 ID、草稿 ID、客户端 ID、标签、完整草稿快照、创建时间。
- `ai_provider_profile`: ID、名称、提供商类型、Base URL、模型、密钥环境变量名、启用状态、更新时间。

## 验收

- Excel 模板可下载；合法导入、错误预览、导出与人工 CRUD 有覆盖测试。
- TXT 解析仅接收本地文件，并可将有效条目写入 SQLite。
- 风险检测、版本恢复/比较、Markdown 下载有后端测试。
- 前端 API 映射与构建通过；完整 pytest、Vitest、H5 与微信构建通过。
- MySQL/PostgreSQL 脚本包含现有和新增全部表。
