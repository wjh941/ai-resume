# Web 留存链路加固设计

## 目标

减少 Web 工作台中的状态丢失和跨端阻断，让用户可以在当前浏览器完成连续的求职准备、数据管理和恢复操作。

## 方案

- 在现有动态工作区外包裹 Vue `KeepAlive`，切换页面时保留组件输入、筛选和结果状态。
- `requestApi` 和下载请求遇到 401 时清理会话并派发窗口级过期事件；应用壳监听事件并回到登录界面。
- 增加带 Bearer 鉴权的二进制下载请求，账户页调用现有数据导出接口并触发浏览器下载。
- 岗位对比资料缺失提示改为当前 Web 工作区可执行的职业规划入口，不再要求用户切换小程序。

## 范围与约束

保持现有 Vue、Fetch 和 API 契约，不新增依赖，不改变后端接口；KeepAlive 只覆盖工作区视图，简历编辑器仍由 URL 草稿上下文单独控制。

## 验收标准

1. 切换工作区后返回，已有输入和结果仍在。
2. 任一 API 返回 401 时，工作台自动显示登录面板。
3. 账户数据导出从 Web 端直接下载 ZIP，并显示可读的成功/失败状态。
4. Web 页面不再把可执行的当前端流程引导到小程序。
